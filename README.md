# LoveAdaptation

Система динамической адаптации окружения — игроки получают способности в зависимости от того, сколько времени они проводят в определённых биомах и измерениях.

## Общая структура

LoveAdaptation отслеживает, сколько игрок проводит времени в воде, Адском измерении, пещерах, на пустошах и других локациях. По мере накопления опыта (в виде часов/тиков в том или ином месте) игрок разблокирует «адаптации» — кастомные способности с эффектами, бонусами к скорости, защите и т.д. Каждая адаптация может иметь несколько стадий (базовая, продвинутая), деградирует если не используется, и применяется автоматически при нахождении в соответствующей локации.

## Команды

| Команда | Алиасы | Описание | Пермишин |
|---|---|---|---|
| `/loveadaptation` | `la`, `adaptation`, `adaptations`, `адаптация` | Открыть меню адаптаций, посмотреть прогресс (`info`) | `loveadaptation.use` |
| `/loveadaptationadmin` | `laadmin`, `лаадмин` | Администраторские команды | `loveadaptation.admin` |

### Подкоманды `/loveadaptation`

- `menu` (или без аргументов) — открыть меню адаптаций
- `info [player]` — показать прогресс адаптаций (свой или указанного игрока)
- `help` — показать список команд

### Подкоманды `/loveadaptationadmin`

- `reload` — перезагрузить config.yml
- `reset <player>` — сбросить прогресс адаптаций игрока
- `check <adaptationId> [player]` — показать детальный прогресс конкретной адаптации
- `givepotion <player> <1|2>` — выдать зелье адаптации указанного уровня

Старые пути `/loveadaptation reset|check|givepotion|reload` больше не выполняют действие — они
перенаправляют администратора короткой подсказкой на `/loveadaptationadmin`, чтобы команда,
набранная по привычке, не пропадала молча.

## Пермишины

| Пермишин | Описание | Default |
|---|---|---|
| `loveadaptation.use` | Доступ к `/loveadaptation` и меню | true |
| `loveadaptation.admin` | Доступ ко всем админ-командам | op |

## Конфигурация (`config.yml`)

### Базовая адаптация

```yaml
base_adaptation:
  enabled: true
  name: "Базовая форма"             # отображение
  color: "&7"                       # цвет в интерфейсе
  head_texture: "eyJ0ZXh0dXJlcyI..."  # кастомная текстура головы (base64)
```

### Адаптации по локациям

```yaml
adaptations:
  water:                            # адаптация к воде
    enabled: true
    name: "Дельфин"
    description: "Ускорение в воде и улучшенное дыхание"
    color: "&9"
    unlock_hours: 15                # разблокируется через 15 часов в воде
    required_ticks: 1080000         # эквивалент 15 часов
    max_progress_percent: 90.0      # максимум прогресса (90% = предел деградации)
    bonus_threshold_percent: 90.0   # порог для активации бонусных эффектов
    head_texture: "eyJ0ZXh0dXJlcyI..."
    degradation_rate_percent_per_hour: 5.0  # теряет 5% прогресса в час вне воды
    
    # Базовые эффекты (при активации адаптации)
    effects_base:
      - type: "SPEED"
        level: 2                    # уровень эффекта (1-5)
        apply_in: ["WATER"]        # где применяется (WATER, NETHER, CAVE, OVERWORLD, etc.)
    
    # Бонусные эффекты (при 90%+ прогресса). CONDUIT_POWER (иммунитет к утоплению)
    # намеренно вынесен сюда, а не в effects_base — иначе игрок мог бы висеть в
    # воде AFK бесконечно сразу после разблокировки адаптации.
    effects_bonus:
      - type: "SPEED"
        level: 3                    # усиленная скорость при бонусе
        apply_in: ["WATER"]
      - type: "DOLPHINS_GRACE"
        level: 1
        apply_in: ["WATER"]
      - type: "CONDUIT_POWER"
        level: 1
        apply_in: ["WATER"]
    
    # Модификаторы
    hunger_modifier_base: 1.0       # x1.0 голода (обычно)
    hunger_modifier_bonus: 0.9      # x0.9 голода при бонусе (экономия еды)

  nether:                           # адаптация к Адскому измерению
    enabled: true
    name: "Адепт огня"
    description: "Снижение урона от огня и лавы"
    color: "&c"
    unlock_hours: 12
    required_ticks: 864000
    max_progress_percent: 90.0
    bonus_threshold_percent: 90.0
    head_texture: "..."
    degradation_rate_percent_per_hour: 5.0
    
    effects_base:
      - type: "FIRE_RESISTANCE"
        level: 1
        apply_in: ["NETHER"]
    
    effects_bonus:
      - type: "FIRE_RESISTANCE"
        level: 2
        apply_in: ["NETHER"]
      - type: "RESISTANCE"
        level: 1
        apply_in: ["NETHER"]
    
    fire_damage_reduction_base: 0.4  # базовое снижение урона огня на 40%
    fire_damage_reduction_bonus: 0.5 # при бонусе — на 50%

  cave:                             # адаптация к пещерам
    enabled: true
    name: "Зрение во мраке"
    description: "Ночное видение в пещерах и подземелье"
    color: "&8"
    unlock_hours: 10
    # ... остальные параметры
```

## Механика адаптации

1. **Отслеживание времени** → плагин отслеживает каждый тик, который игрок находится в определённой локации
2. **Накопление прогресса** → каждые 50 тиков добавляется 1 единица прогресса к адаптации
3. **Разблокировка** → при достижении `required_ticks` адаптация разблокируется (игрок получает уведомление)
4. **Применение эффектов** → когда игрок находится в соответствующей локации и адаптация разблокирована, применяются эффекты
5. **Деградация** → если игрок не находится в локации, адаптация теряет `degradation_rate_percent_per_hour` прогресса в час
6. **Бонусы** → при прогрессе ≥ `bonus_threshold_percent` применяются усиленные эффекты

## Интеграции

### LoveCore

Данные об адаптациях могут быть связаны с ProfileOracle для отображения в профилях.

### LoveClans

Адаптации членов клана могут влиять на боевую мощь клана в войнах (опционально).

### LoveBehavior

Хорошее поведение (высокий рейтинг) может ускорять деградацию адаптаций или защищать от потери.

### PlaceholderAPI

Плейсхолдеры для отображения текущей адаптации, прогресса, временем до разблокировки.

## Зависимости

### Обязательные

- **Paper 1.21** — базовый Minecraft сервер

### Мягкие зависимости

- **PlaceholderAPI** — интеграция плейсхолдеров
- **LoveCore** — служба профилей и данных
- **LoveClans** — интеграция с кланами (бонусы в войнах)
- **LoveBehavior** — интеграция с системой репутации (модификаторы деградации)

## Структура данных

- `player_adaptations` — текущее состояние адаптаций (игрок, адаптация, прогресс, дата последнего обновления)
- `adaptation_history` — история разблокировок и потерь адаптаций (для логов)
- `location_tracking` — отслеживание времени в локациях (для внутренних расчётов, может быть временным)

## PlaceholderAPI

| Плейсхолдер | Описание |
|---|---|
| `%loveadaptation_current%` | Текущая активная адаптация |
| `%loveadaptation_progress_<adaptId>%` | Прогресс адаптации в % |
| `%loveadaptation_unlocked_count%` | Количество разблокированных адаптаций |
| `%loveadaptation_hours_<adaptId>%` | Часов в локации адаптации |

## Локации

- `water` — Вода (биомы с водой, или вода в общем)
- `nether` — Адское измерение (The Nether)
- `cave` — Пещеры (Y < 60 в Overworld)
- `end` — The End (опционально)
- `sky` — Небо (Y > 120, опционально)
